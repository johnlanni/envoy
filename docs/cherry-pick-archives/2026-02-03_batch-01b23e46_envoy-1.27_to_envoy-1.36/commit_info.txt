fix(wasm): avoid clearing buffer when not modifying it
问题描述

  这是一个关于 WASM 过滤器请求数据缓冲区处理 的 bug 修复。

  核心问题：
  modifyDecodingBuffer 函数会执行两个操作：
  1. 将原始缓冲区移动到内部缓冲区
  2. 清空当前缓冲区

  这在需要修改缓冲区时是正确的行为，但原来的逻辑存在一个问题：即使不需要修改数据，也会调用这个函数，导致缓冲区被意外清空，造成数据丢失。
Link: https://code.alibaba-inc.com/Ingress/envoy/codereview/25492862
* fix(wasm): avoid clearing buffer when not modifying it

The modifyDecodingBuffer call moves the original buffer to an
internal buffer and clears the current buffer. This is correct when
the buffer will be modified, but the original logic could clear the
buffer even when no modifications were planned, leading to data loss.

Only call modifyDecodingBuffer when buffering_request_body_ is true,
which indicates the buffer will actually be modified.
