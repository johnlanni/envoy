    support wasm tracing in http call and redis call
    
    This commit adds distributed tracing support for Wasm filters when making
    HTTP and Redis calls. Key changes include:
    
    1. HTTP Call Tracing:
       - Set parent span from current stream context (decoder/encoder callbacks)
       - Set child span name with plugin and cluster information
       - Format: "wasm <plugin_name> httpcall to <cluster>"
    
    2. Redis Call Tracing:
       - Add RedisRequestOptions parameter to send() method
       - Set parent span and child span name similar to HTTP calls
       - Format: "wasm <plugin_name> rediscall to <cluster>"
    
    3. Test Updates:
       - Add mock span setup in test cases
       - Verify parent span and child span name are set correctly
       - Update Redis mock to accept RedisRequestOptions parameter
    
    4. Macro Consistency:
       - Replace ALIMESH macro with HIGRESS for consistency with target branch
       - Remove conditional compilation guards from httpCall tracing code
