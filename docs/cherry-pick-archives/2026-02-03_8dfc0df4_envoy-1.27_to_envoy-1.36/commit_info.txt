    * fix: prevent WASM VM accumulation during rebuild by tracking old handle lifetime
    
    The rebuild() function previously allowed creating new VMs even when old VMs
    were still in use by long-running requests, causing memory accumulation.
    
    Changes:
    - Add weak_ptr<PluginHandle> old_handle_ member to track previous VM instance
    - Check if old handle is still alive before allowing rebuild
    - Only permit rebuild when previous VM has been fully released
    - Store current handle as weak_ptr before replacing with new one
    
    This ensures at most one old VM instance exists at any time, preventing
    unbounded memory growth while maintaining the existing time-based throttling
    mechanism.
